# COSMO ECO 🌍
### Unified Space Sustainability Intelligence

Cosmo Eco is a space sustainability intelligence platform designed to make orbital sustainability, space debris, and the environmental impact of space activities easier to understand and explore.

It brings together orbital monitoring, sustainability indicators, environmental context, and interactive visualization into one platform.

Built for **ASTRA 2026 Hackathon**.

---

## 🚀 Project Overview

Earth's orbit is becoming increasingly crowded with satellites and space debris. Sustainable space operations require better awareness of orbital congestion, collision risks, satellite lifecycles, and the long-term environmental consequences of space activities.

Cosmo Eco aims to make this information more accessible through an interactive platform that helps users explore orbital sustainability and understand the importance of responsible space operations.

### Our Mission

To promote responsible space exploration by making space sustainability data understandable, visual, and accessible.

---

## ✨ Features

### 🛰️ Orbit & Space Debris Monitoring
- Visual exploration of satellites and orbital objects.
- Orbital awareness and debris-related information.
- Exploration of orbital congestion and space sustainability.

### 🌱 Space Sustainability Score
- A sustainability scoring framework for evaluating space missions.
- Considers orbital debris risk, collision risk, mission lifetime, disposal planning, fuel efficiency, launch environmental impact, atmospheric impact, and reusability.

### 🔮 What-If Sustainability Simulator
- Explore how changes in mission parameters may influence sustainability.
- Understand the impact of different orbital and mission planning decisions.

### 🌎 Environmental Intelligence
- Connect space sustainability with environmental awareness.
- Explore environmental data and relevant Earth observation insights.

### 🤖 AI Sustainability Advisor
- An AI-oriented interface designed to help users understand sustainability concepts.
- Provides simplified explanations of space sustainability indicators and concepts.

## 💻 Installation and Setup

Follow these steps to run Cosmo Eco on your local machine.

### Prerequisites

Install the following tools:

- Node.js
- pnpm
- Git

Verify the installations by opening a terminal and running:

```bash
node -v
pnpm -v
git -v
```

---

### Step 1: Clone the Repository

Clone the project from GitHub:

```bash
git clone https://github.com/YOUR-USERNAME/cosmo-eco.git
```

Replace `YOUR-USERNAME` with the GitHub username of the repository owner.

### Step 2: Navigate to the Project Directory

```bash
cd cosmo-eco
```

### Step 3: Install Dependencies

Install all required packages:

```bash
pnpm install
```

### Step 4: Run the Development Server

Start the local development server:

```bash
pnpm dev
```

### Step 5: Open the Application

Open your browser and visit:

```text
http://localhost:3000
```

Cosmo Eco should now be running locally.

To stop the development server, press `Ctrl + C` in the terminal.

## 🌱 Sustainability Framework

Cosmo Eco explores space sustainability through the following indicators:

- Orbital debris risk
- Collision risk
- Mission lifetime and disposal planning
- Fuel efficiency
- Launch environmental impact
- Atmospheric impact during re-entry
- Reusability and repairability

The sustainability score is designed as an exploratory framework to encourage awareness and comparison of space sustainability factors.
